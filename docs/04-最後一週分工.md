## 四、測試週（10/21 → 10/23）的規則

1. **只改自己領域的檔案。** 要動別人的，先在群組講、等對方說好。領域對照在 `backend/app/ownership.py`
   （`python -m app.ownership` 會印出來）。
2. **改之前先拉、改完先測再推**：
   ```bash
   git pull
   cd backend && python -m pytest -q      # 要全部通過
   git push
   ```
3. **回報 bug 的格式**（貼群組）：哪一頁／哪一支 API、做了什麼、預期什麼、實際怎樣、截圖。
   丟給負責那個領域的人，他請 AI 修。
4. **不可以實作 `POST /api/auth/switch`**（家長切換成孩子的帳號）——這是設計上刻意不做的。
5. **機密不進 repo**：`JWT_SECRET`、`MODEL_API_KEY`、`ADVICE_API_KEY`、`BREVO_API_KEY`、`MAIL_FROM`、`ADMIN_EMAILS`
   只填在 `backend/.env` 與 Render 後台。
