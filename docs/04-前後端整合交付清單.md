## 如何啟動

以下從專案根目錄執行。現有 `.venv` 已可執行；換新電腦時請先依根目錄 README 與 `model_training/requirements.txt` 安裝環境。

1. 開啟 Docker Desktop（既有啟動器預設使用本機 PostgreSQL）。
2. 在 `backend/.env` 設定模型服務：

   ```dotenv
   MODEL_BASE_URL=http://127.0.0.1:8081
   MODEL_NAME=expense-qwen-0.5b-lora
   MODEL_TIMEOUT_SECONDS=90
   ```

3. 第一個終端啟動模型服務：

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn serve:app --app-dir model_training --host 127.0.0.1 --port 8081
   ```

4. 第二個終端啟動前後端：

   ```powershell
   .\.venv\Scripts\python.exe run.py
   ```

5. 開啟啟動器印出的完整網址，預設為 `http://localhost:5174/?api=http://localhost:8000`。正常啟動不需要加 `--reset`。

模型首次解析才載入權重，因此第一次比較慢。`http://127.0.0.1:8081/healthz` 的 `modelLoaded=false` 在首次解析前是正常的。

模型放在其他位置或之後部署時，請參考 [模型服務說明](../model_training/README.md#模型服務)。啟動器會建立開發用帳號，因此上述流程用途為本機開發；正式主機要另外配置服務啟動、資料庫與密鑰。
