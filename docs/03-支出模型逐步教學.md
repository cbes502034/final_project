# 恢復後從哪裡開始學

完整操作方式請看 [模型程式說明](../model_training/README.md)。

第一步先執行 `model_training/inference.py "午餐100 晚餐200"`。

然後依序理解：

1. `ExpenseModel.__init__` 載入 Qwen 基底與已有的 LoRA 權重。
2. `messages()` 組成 system 規則與 user 文字。
3. `generate()` 使用 chat template，把文字轉成模型 token，生成原始答案。
4. `parse()` 將答案轉成 JSON，再驗證分類、品項與金額。
5. 使用 `--raw` 可以分清楚模型原始答案與程式修正後答案。

`train.py` 才是在修改 LoRA 參數；執行 `inference.py` 不會修改模型、重訓或寫入帳務資料。

模型原型曾使用 150 筆合成訓練資料訓練 120 步。91 筆合成測試的原始完整正確率為 87.9%，程式驗證後為 98.9%。這是先前報告的成績，程式規則曾依測試修正，並非真實使用者的盲測成績。

這次恢復沒有重新訓練既有模型，也未回退專題整合版本。訓練程式預設輸出新的資料夾，避免覆蓋原有權重。
