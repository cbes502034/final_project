# 手動待辦（只有人能做的事）

> 程式、測試、評測工具、截圖、簡報都做完了。下面是**需要你本人**動手的部分，依重要程度排。
> 每一項都寫了「不做會怎樣」，時間不夠時可以照這個決定要不要做。

---

## 1. 報告前一定要做

### 1-1 看過簡報、改成你們的說法（30 分鐘）
- 打開 `report/家庭記帳_期末報告.pptx`（20 頁，每頁下方「備忘稿」有講稿）
- 確認封面的課程名稱、日期；不想要的頁直接刪
- 如果你在 PowerPoint 裡改了字，**之後就不要再跑 `node report/build_deck.js`**（會整份重新產生、蓋掉你的修改）。
  想讓模型成績自動更新的話，先更新數字、最後再手改

### 1-2 準備現場展示（20 分鐘）
- 線上站：<https://fambudget-web.onrender.com>
- **上台前 5 分鐘先打開一次**：Render 免費方案閒置會休眠，第一次開要等 30～60 秒
- 線上站沒有示範資料：先用自己的帳號記幾筆（收入一筆、支出幾筆），建一個家庭、產生一組邀請碼，展示時才有東西看
- 建議展示順序：首頁 → 記一筆（段落記帳）→ 收支明細 → 統計 → 家庭成員（邀請碼）→ 財務建議

> 不做會怎樣：上台時畫面空空的，或卡在 Render 開機。

---

## 2. 線上站要真的用 AI（建議做）

現在線上站**沒有接模型**：段落記帳用前端規則、財務建議用前端版本，功能照常但不是 AI。要接的話：

1. 申請一把商業 API 金鑰（建議 Claude：console.anthropic.com → Billing 儲值 → API Keys）
2. Render 後台 → 後端那個服務 → **Environment** → 新增：

   | 名稱 | 值 |
   |---|---|
   | `MODEL_PROVIDER` | `anthropic` |
   | `MODEL_API_KEY` | 你的金鑰（**不要貼到群組、不要 commit**） |
   | `MODEL_TIMEOUT_SECONDS` | `60` |

3. 存檔後等它重新部署，到線上站段落記帳貼一段話試試

> 不做會怎樣：報告時 AI 的部分只能用「本機 Ollama 跑的評測結果」與截圖說明，線上站展示不到真的 AI 解析。
> 你電腦上的 Ollama 模型線上站連不到，只能本機用。

## 3. Render 部署檢查（10 分鐘）

- Render 後台 → 後端服務 → **Events**：最近幾次部署有沒有成功（這兩天 `requirements.txt` 多了 `anthropic` 套件）
- 有失敗的話，把錯誤訊息貼給 AI 修
- （選做）忘記密碼要能寄信：Environment 填 `BREVO_API_KEY`、`MAIL_FROM`
- （選做）展示平台管理員：Environment 填 `ADMIN_EMAILS`，再到 Render 的 Shell 跑 `python -m app.cli make-admin`

## 4. 報告要寫「人工抽查」才需要（20 分鐘）

留出集 `backend/eval/heldout.jsonl` 的答案是 AI 產生、程式驗算過（金額、日期、收支、分類 0 錯），**還沒有人看過**。
報告想寫「人工抽查 N 題」的話：

- 隨便挑 20～30 題，看答案合不合理（「今天」是 2026-10-14 禮拜三）
- 看過的那一題把 `"checked": false` 改成 `"checked": true`
- 改完在 `backend/` 底下跑 `python -m pytest tests/test_evaluation.py -q`，再重產簡報（第 6 節）

> 不做會怎樣：簡報上會寫「人工抽查 0 題」，照實講就好。

## 6. 要更新簡報上的數字時（指令）

```bash
# 模型評測（本機 Ollama；中斷了同樣指令再跑一次會接續）
cd backend
set MODEL_PROVIDER=openai& set MODEL_BASE_URL=http://localhost:11434& set MODEL_NAME=deepseek-r1:1.5b& set MODEL_MAX_TOKENS=4096& set MODEL_TIMEOUT_SECONDS=300& python tools/eval_nlp.py --label deepseek-r1-1.5b

# 重產簡報（會蓋掉 PowerPoint 裡的手動修改）
cd ..
python report/collect.py
cd report && npm install && node build_deck.js
```
