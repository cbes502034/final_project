# 手動待辦（只有人能做的事）

> 程式、測試、評測、截圖、簡報、兩份測試報告（PDF）與測試流程影片都做完了。
> 下面是**需要你本人**動手的部分，依重要程度排；每一項都寫了「不做會怎樣」。

---

## 1. 報告前一定要做

### 1-1 看過簡報、改成你們的說法（30 分鐘）
- 打開 `report/家庭記帳_期末報告.pptx`（22 頁，每頁下方「備忘稿」有講稿；封面與結尾有網站的 QR code）
- 確認封面的課程名稱、日期；不想要的頁直接刪
- 如果你在 PowerPoint 裡改了字，**之後就不要再跑 `node report/build_deck.js`**（會整份重新產生、蓋掉你的修改）

### 1-2 準備現場展示（20 分鐘）
- 線上站：<https://fambudget-web.onrender.com>（線上的段落記帳與財務建議接的是 Claude）
- **上台前 5 分鐘先打開一次**：Render 免費方案閒置會休眠，第一次開要等 30～60 秒
- 建議展示順序：首頁 → 記一筆（段落記帳）→ 收支明細 → 統計 → 家庭成員（邀請碼）→ 財務建議 → 平台管理頁

> 不做會怎樣：上台時卡在 Render 開機。

---

## 2. 線上的平台管理員帳號（展示平台管理頁才需要，10 分鐘）

平台管理頁看得到每個帳號的紅綠燈、錯誤訊息、安全事件，但**讀不到任何人的帳**。

1. 在線上站用一個**新的 email 註冊**一個帳號（例如名字叫「平台管理員」），註冊完**不要建家庭、不要記帳**
2. Render 後台 → 後端服務 → **Environment** → `ADMIN_EMAILS` 設成**只有這個 email**
3. 存檔、等它重新部署：服務啟動時會自動把這個帳號設成平台管理員
4. 用那個帳號登入，會直接進到平台管理頁

⚠️ 已經加入家庭或記過帳的帳號**不會**被設成管理員（設了他就看不到自己的帳）——填錯成家長的信箱也不會出事，
只是那個帳號不會變成管理員（Render 的 Logs 會寫原因）。

> 不做會怎樣：簡報「平台管理」那頁只能用截圖說明。

## 3. 報告要寫「人工抽查」才需要（20 分鐘）

留出集 `backend/eval/heldout.jsonl` 的答案是 AI 產生、程式驗算過（金額、日期、收支、分類 0 錯），**還沒有人看過**。
報告想寫「人工抽查 N 題」的話：

- 隨便挑 20～30 題，看答案合不合理（「今天」是 2026-10-14 禮拜三）
- 看過的那一題把 `"checked": false` 改成 `"checked": true`
- 改完在 `backend/` 底下跑 `python -m pytest tests/test_evaluation.py -q`，再重產簡報（第 5 節）

> 不做會怎樣：簡報上不提人工抽查，照實講「答案由 AI 產生、程式驗算過」。
