## 1. 抽查留出集（10/16 前，**最重要**）

留出集 `backend/eval/heldout.jsonl` 的答案是 AI 產生的。答案錯了，量出來的成績就是錯的——所以要人看過。

每一題長這樣：

```json
{"id": "h062", "today": "2026-10-14", "text": "上禮拜三繳了管理費",
 "items": [{"date": "2026-10-07", "amount": null, "kind": "expense", "cat": "居住"}],
 "tags": ["single", "no-amount", "weekday"], "source": "ai", "checked": false}
```

「今天」固定是 **2026-10-14（禮拜三）**。所以：昨天 10-13、前天 10-12、大前天 10-11、這禮拜一 10-12、
上禮拜三 10-07、上週五 10-09；「20號」還沒到 → 算上個月 09-20。

**至少看 30 題**：所有標 `hard`、`weekday`、`multi` 的，再隨便挑幾題。每一題看四件事：

1. 切成幾筆對不對（`items` 的數量）
2. 每一筆的日期、金額（沒講就是 null）、收支、分類
3. 分類有沒有更合理的選擇？（例如「給小孩零用錢」算支出的「其他」，你覺得呢？）有爭議的在群組討論，決定後改
4. 看過、確定沒問題 → `"checked": true`；有錯 → 改掉再設 `true`

```bash
cd backend
python -m pytest tests/test_evaluation.py -q     # 會檢查格式，也會用程式驗算日期答案
git add eval/heldout.jsonl && git commit -m "留出集：人工抽查 N 題" && git push
```

## 測試清單：認證領域＋部署（10/20～10/22）

| # | 操作 | 預期 |
|---|---|---|
| 1 | 註冊新帳號 → 登入 | 進得去首頁，看到「嗨，名字」 |
| 2 | 密碼打錯 | 「email 或密碼不對」，不會說是哪一個錯 |
| 3 | 忘記密碼 → 收信 → 點連結改密碼 | 收得到信；舊密碼不能用、新密碼可以 |
| 4 | 閒置超過權杖有效期 | 跳出「閒置太久」的提示，可以選繼續或重新登入 |
| 5 | 登出 → 按上一頁 | 回不去，要重新登入 |
| 6 | 個人資料改名字、換大頭貼、改密碼 | 改得動；改密碼後其他裝置被登出 |
| 7 | 「登出所有裝置」 | 另一個瀏覽器也被登出 |
| 8 | 平台管理員帳號登入 | 只看得到使用者清單與停權，**看不到任何人的帳** |
| 9 | 管理員停權一個帳號 | 那個帳號登不進去 |
| 10 | 線上站重新整理、隔天再開（Render 免費方案會睡） | 第一次比較慢，但會起來 |
| 11 | `python -m app.cli check-config` | 每一項都是 ✓，或是知道為什麼是 ✗ |
