## 1. 抽查訓練資料（10/17 前）

`ml/data/train.jsonl` 是 `ml/make_data.py` 用模板產生的 1500 題，給微調用（加分項）。
模板寫錯的話，1500 題會一起錯，所以要人看。隨機抽 30 題：

```bash
python -c "import json,random; rows=[json.loads(l) for l in open('ml/data/train.jsonl',encoding='utf-8')]; [print(r['today'], r['text'], [(i['date'], i['amount'], i['kind'], i['cat']) for i in r['items']]) for r in random.sample(rows, 30)]"
```

每一題看：句子通不通順、切幾筆、日期（注意每一題的「今天」不一樣）、金額、收支、分類。

## 測試清單：家庭領域（10/20～10/22）

需要兩到三個帳號（自己開幾個測試用的）。

| # | 操作 | 預期 |
|---|---|---|
| 1 | A 建立家庭 | A 是家長 |
| 2 | A 產生邀請碼（填標題、選身分） | 邀請碼只顯示一次；關掉就拿不回來；列表看得到標題與到期時間 |
| 3 | B 用邀請碼加入 | B 進家庭，身分跟 A 選的一樣 |
| 4 | 同一個邀請碼再用一次 | 不行（已用過） |
| 5 | A 刪掉一個還沒用的邀請碼 | 列表少一個；那個碼不能用了 |
| 6 | A 用帳號直接邀請 C → C 接受／拒絕 | 接受就進家庭；拒絕就消失 |
| 7 | A 把 B 設成被照看的孩子 | A 看得到 B 的帳；B 看不到 A 的 |
| 8 | B（被照看的孩子）記一筆帳 | A 的鈴鐺有通知；B 自己沒有 |
| 9 | 通知全部標已讀、單筆標已讀 | 紅點消失 |
| 10 | A 把 B 移出家庭 | B 回到「還沒有加入家庭」 |
| 11 | 只剩一個家長時，家長想改成子女或退出 | 擋下來，說明為什麼 |
| 12 | 解散家庭 | 成員都回到沒有家庭的狀態 |
