# 前端設計規格（使用者指定，不可違背）

1. **深色主題**，整體要有科技感。
2. **禁止弧形與圓形**：`border-radius` 一律 0，所有元件用稜角。切角只能用 `clip-path` 做**斜切直角**，不可做圓角。
3. **背景要有科技感圖騰裝飾**：網格線、掃描線、電路走線、座標刻度、雜訊等（用 CSS/SVG 產生，不外連圖檔）。
4. **滑鼠移到可點選元件上時，用螢光蒂芬妮綠**（fluorescent Tiffany blue-green）作為 hover 色。
   - 主色 `--c-accent: #0ABAB5`（蒂芬妮綠本色）
   - hover 螢光 `--c-glow: #2BFFE0`，搭配 `text-shadow` / `box-shadow` 產生螢光感
5. **RWD**：手機（≤480px）、平板（≤900px）、桌機三段式；手機上內容必須完整可讀，表格要可橫向捲動、圖表要縮放。
6. 字體：等寬字（科技感）搭配無襯線中文字體；中文用系統字（Noto Sans TC / 微軟正黑體）避免外連字型失敗。

> 這份規格套用到 `site/` 底下所有頁面。

---

## 7. 質感定位（使用者補充，優先級最高）

整份網頁要看起來**具備專業性**，是「工程師風格」，不是兒戲、也不是設計競賽作品。

**具體判準：**

- 走**工程文件 / 規格書 / 終端機**的調性，不是視覺特效展示。
- 資訊密度要高：表格、數據、欄位、編號、標籤，能用表格就不要用大圖。
- 標籤與數值用**等寬字**，對齊要精準，欄位命名像規格書（如 `MODEL / DATASET / LATENCY`）。
- 顏色克制：底色＋灰階為主，螢光蒂芬妮綠**只用在 hover 與關鍵強調**，不可整頁亂灑。
- **不要**大量動畫、不要漸層滿版、不要 emoji 當裝飾、不要卡通感插圖。
- 背景圖騰要**低對比、細線條**，是襯底而不是主角。
- 每個數字都要能對應到研究來源，畫面上要看得出「這是有依據的分析」而不是排版練習。

## 8. 圖表風格：半導體 / 電路板語彙（使用者補充）

因為專案含硬體（樹莓派）成分，**專案結構圖與流程圖採用半導體風格**繪製（全部用 inline SVG，不外連）。

**具體語彙：**

- 模組方塊畫成 **IC 封裝**：矩形本體 + 兩側/四側接腳（pin）短線，左上角有 pin-1 方形標記。
- 連線畫成 **PCB 走線**：只走水平/垂直/45 度，轉角是直角或斜切，不可用曲線（Bezier 一律禁止）。
- 連接點畫成 **焊墊 / via**：小方塊或同心方框，不用圓點。
- 分區用 **die / 晶片區塊**風格：細框 + 內部網格 + 角落缺角標記。
- 標註用等寬字，像 datasheet 的 pin name（如 `IN0`、`CLK`、`OUT`），旁邊附中文說明。
- 資料流方向用**箭頭三角形**（實心直角三角），不用圓弧箭頭。
- 顏色：線條走灰階，關鍵路徑才上蒂芬妮綠；hover 時該路徑亮起。
