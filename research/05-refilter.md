## 12-2 這一關新增的三條強制設計約束

研究過程發現的風險，**必須反寫回所有 Top 20 的設計中**，不是只寫在風險欄：

1. **樹莓派一律不跑主推論。** 依據 Pi 5 實測 1.5B 僅 5–15 tok/s、3B 僅 2–5 tok/s [S31]，
   Pi 的角色只能是：資料採集、本地前處理、輕量分類／路由、離線降級顯示、受監控的 Linux endpoint。
2. **所有外部 API 一律先落地成本地快取，Demo 不打線上 API。**
   依據 NVD 無 key 30 秒 5 次 [S25]、環境部 API 每次 1,000 筆 [S17]、TDX 未註冊 50 次/日 [S18]。
3. **高風險領域（醫藥、用藥、示警）的關鍵事實不得由模型生成，必須走查表／FC 取回並附出處。**
   依據小模型幻覺與 FC 選錯工具的實測落差 [S28][S33]。
