> 每個候選記錄 20 個欄位（壓縮成固定區塊格式）。欄位縮寫：
> `PROB` 問題 / `USER` 目標使用者 / `NOW` 目前怎麼處理 / `PAIN` 實際痛點 / `DATA` 資料來源 /

## A 群：資訊安全

### C01 SOC 告警分流與處置建議系統
- **PROB** L1 分析師每班次面對 1,000–5,000 則告警，46% 是誤報 [S1]
- **USER** 中小企業 IT／MSSP L1 分析師、校園網管
- **NOW** 人工開 SIEM，逐則看，跨 10.9 個主控台交叉比對 [S1]
- **PAIN** 每天 3 小時純 triage；67% 事件沒被處理；分析師 2 年就離職 [S1]
- **DATA** 公開 log/告警資料集（HDFS、BGL、Thunderbird、Spirit [S34]）＋自建中文告警標註集
- **WHY-LLM** 告警是半結構化文字，判斷「這是不是真的」需要語意理解＋上下文整合，規則寫不完
- **FT** 高：分類頭（真/假陽性、嚴重度）用 ModernBERT，敘事用 ≤4B LoRA [S29]
- **EVAL** 高：Accuracy / F1 / 誤報降低率 / Base vs FT 對照
- **PI** 中：當 log collector edge agent（rsyslog→本地前處理→上送）
- **FC** 高：需要即時查資產清單、查 IP 信譽、查歷史相似事件
- **DEPLOY** 高：FastAPI＋PostgreSQL＋前端，Docker Compose
- **DEMO** 上傳一批告警 → 3 秒內出分流結果與處置建議
- **TEAM** A 架構＋Pi＋FC；B 資料集與分類模型；C 標註規則與 Prompt；D 前端與評測報表
- **RISK** 中文告警資料要自建；幻覺處置建議
- **1M** 高
- **VALUE** 高（每年 33 億美元人工成本 [S1]）
- **BIZ** 高（Cofense/Torq/Panther 已商業化 [S2][S3]）
- **ALT** Torq、Panther、Microsoft Security Copilot
- **DIFF** 開源自架、中文、可離線、不綁 SIEM
- **PROD** 高
