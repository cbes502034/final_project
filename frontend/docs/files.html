00

讀這棵樹之前

前端與後端是兩個獨立的東西

frontend/ 是純靜態網頁，沒有建置步驟，用瀏覽器打開就會動。 它跟後端之間只透過 js/api.js 這一層講話—— 把 <meta name="api-base"> 留空就用示範資料， 填上網址就打真的後端，畫面程式碼一行都不用改。

後端分四層，每一層只跟相鄰的講話

routers/    收請求、驗權限、回結果      ← 不寫計算
    ↓
services/   真正做事：計算、規則         ← 不碰 HTTP
    ↓
models/     資料表長什麼樣               ← 不寫商業邏輯
    ↓
PostgreSQL

schemas/    橫在旁邊：定義 API 進出的形狀

models/ 回答資料庫裡存什麼，schemas/ 回答API 收送什麼。 分開的好處立刻看得到：使用者表一定要存密碼雜湊， 但任何一支 API 都不該把它送出去——response model 裡根本沒有那一欄， FastAPI 會自動濾掉，你不可能不小心送出去。

樹上的顏色

藍字 ★ 關鍵檔案，動工前先看過
綠字 已經寫好、完整可用，直接 import，不要改
黃字刪除線 現在還不存在，你們自己 mkdir。 那是後端開發的主體，先給空檔案就變成填空題了
.env 絕對不可以 commit

裡面有 JWT_SECRET——拿到它的人可以偽造任何人的登入權杖。 而且 git 的歷史刪不掉：下一個 commit 刪掉它，舊版本還在歷史裡。
真的不小心 commit 了，唯一的補救是立刻換一組新密鑰。
要告訴別人需要哪些變數，用 .env.example——只有名稱沒有值。
同樣不進版控：__pycache__/、 .venv/、.pytest_cache/、*.db、.DS_Store

02

每個路徑放什麼

要改東西時，從這張表找檔案。

路徑放什麼誰動它
frontend/index.html整個系統的畫面骨架。新增一個畫面要在這裡加導覽項目前端
frontend/js/api.js★ 唯一的資料入口。mock 與 http 兩套實作簽名完全相同，切換只改 <meta name="api-base">前端
frontend/js/app.js每個畫面怎麼畫、怎麼互動。不直接 fetch，一律走 api.js前端
frontend/js/data.js示範資料，同時是資料表草案（schema／relations）。手冊的資料表區塊就是從這裡生出來的前端
frontend/docs/這些說明文件本身，也是靜態網頁共同
backend/app/main.py只負責組裝：掛 CORS、掛路由。不寫任何業務邏輯後端
backend/app/ownership.py★ 誰負責哪些路由、哪些檔案、排程到哪。python -m app.ownership 印出分工表共同
backend/app/toolkit/已經寫好的工具，直接 import，不要改已交付
backend/app/models/資料表長什麼樣。資料庫裡存什麼各自
backend/app/schemas/API 進出的形狀。API 收送什麼——跟 models 分開，密碼雜湊才不會被不小心送出去各自
backend/app/routers/收請求、驗權限、回結果。不寫計算各自
backend/app/services/真正做事：計算與規則。不碰 HTTP，所以可以直接測各自
backend/tests/一致性測試。改了路由沒改文件，這裡會紅共同
docs/02-前後端串接契約.md★ 每一支 API 的請求與回應形狀，以及踩過的坑共同
03

toolkit/ 工具箱

這個資料夾跟其他的差別：它已經寫好了。import 來用，不用讀懂內部。 每支函式的說明裡有參數、回傳、例外與範例。

檔案包住什麼你會用到的
config.pypydantic-settingssettings.database_url
db.pySQLAlchemyBase、get_db
passwords.pypasslib / bcrypthash_password、verify_password
tokens.pyPyJWTmake_access_token、read_access_token
deps.pyFastAPI 依賴current_user_id、paging
errors.pyHTTPExceptionnot_found、forbidden、unauthorized
period.py日期計算month_range、recent_months
money.pyDecimalto_decimal、ratio、quantize
images.py圖片驗證validate_avatar、from_data_uri
alerts.py階段性提醒的門檻計算usage_percent、crossed、should_fire
scope.py可見範圍的兩道篩選visible_users、visible_groups、require_user
roles.py角色能做哪些治理動作（不管可見範圍）can_govern、require_govern、can_set_goal_for
三個約定

1. 不要改 toolkit/ 裡的東西，改了別人會踩到。
2. 不要在裡面寫跟記帳有關的邏輯，這裡的東西換一個題目也要能用。
3. 金額一律走 money 模組，浮點數累加會產生 12345.670000000002。

python -c "from app.toolkit import alerts; help(alerts.crossed)"
