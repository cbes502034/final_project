要串接的話，看這一份：前後端串接契約

這一頁列的是有哪些路由。真正動工時你需要的是 「我要送什麼、後端要吐什麼、前端拿去幹嘛」 —— 那些寫在 docs/02-前後端串接契約.md。
那份文件不是手寫的：它是把前端的 mock 轉接器實際跑起來， 把每一支的真實回傳形狀 dump 出來產生的。 所以照著做就一定接得上，形狀不對畫面就會壞，沒有第三種可能。

後端還沒部署，這頁是規格不是實測

路由與回應形狀來自 frontend/js/api.js 的契約定義，前端目前跑在 mock 模式。 後端上線後 FastAPI 會自動產生可直接送出請求的 /docs， 那時這頁的角色會變成「按人員分工看」，實際試打請用 /docs。
